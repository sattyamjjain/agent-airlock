# Guard-suite corpus

!!! info "One file, two locations"

    The page below is
    [`BENCHMARK.md`](https://github.com/sattyamjjain/agent-airlock/blob/main/BENCHMARK.md)
    from the repository root, included verbatim. It is generated by
    `scripts/generate_benchmark.py` (`make benchmark`), and
    `scripts/generate_benchmark.py --check` runs in CI as a drift gate, so the file
    cannot be edited by hand and cannot be moved without breaking that gate. It is
    included here rather than copied, so there is exactly one of it on disk.

    Read the honest-scope note in the first section before the headline number: this
    is a **self-corpus**, grading agent-airlock against its own fixtures. It is not a
    competitive benchmark and not an adaptive-attacker measurement. For the latter see
    [Adaptive attacker (AgentDojo)](index.md#the-seven-published-rows).
