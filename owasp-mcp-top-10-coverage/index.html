    OWASP MCP Top 10 coverage¶

    Spec: https://owasp.org/www-project-mcp-top-10/ (beta) Last verified (global): 2026-11-10

    The evidence behind the README's MCP Top-10 table. Full: the controls that run on the @Airlock call path cover the risk where it reaches a tool call, and nothing the risk names is out of scope. Partial: part of the risk is out of scope, or the control that covers it runs only where the host calls it. No benchmark in this repository maps its corpus to MCP01-MCP10, so no row has a measured block-rate.

    Risks¶

    Risk ID Risk Coverage Why Last verified Measured block-rate
    MCP01 Token Mismanagement & Secret Exposure Partial On the call path, ArgumentSecretGuard refuses secrets in arguments when a policy sets it, and the sanitizer masks the secrets its detectors find in output; MCPProxyGuard runs only where a proxy calls it. Hard-coded credentials, token lifetime, and secrets the host keeps in model memory or its own logs are out of scope. 2026-11-10 not measured
    MCP02 Privilege Escalation via Scope Creep Partial Agent identity (step 2) and capability gating (step 4) run on every call. CredentialScope runs only where the host calls MCPProxyGuard.validate_tool_credentials(), and the union boundary only at CapabilityCapEngine.grant_lease(). The scopes an authorization server grants a server, and how they grow, are set outside the call boundary. Was Full until 2026-11-10. 2026-11-10 not measured
    MCP03 Tool Poisoning Partial Ghost-argument rejection, the tool-name deny list and SafePath / SafeURL check each call. The description-manifest guard runs only where the host checks a tool at admission, and compares declared arguments and side effects, not instructions written into a description. A poisoned description that steers the model into well-formed calls to allowed tools passes all four; the MCPTox replay counts how often. Was Full until 2026-11-10. 2026-11-10 not measured
    MCP04 Software Supply Chain Attacks & Dependency Tampering Partial The tool-name deny list refuses download_plugin_* / fetch_plugin_* calls on the call path. The Ox stdio defaults screen a server's launch command only where the host calls validate_stdio_command() before spawning it. A tampered package or dependency inside an MCP server is out of scope. Was Full until 2026-11-10. 2026-11-10 not measured
    MCP05 Command Injection & Execution Full Untrusted input reaches a command through a tool argument or a server's launch command, and a control covers each. On the call path, ToolArgSinkGuard (step 2.75) and ShellCommandPolicy (step 2.77) screen arguments when a policy sets them, the tool-name deny list (step 2) refuses shell-shaped tools, and sandbox=True runs the tool in E2B. The stdio guard screens launch commands and CodeSandboxBridgeGuard is a second argument screen; the host calls both. 2026-11-10 not measured
    MCP06 Intent Flow Subversion Partial ToolOutputTrustGuard checks each result after the tool runs when the config sets one, and @requires_human_oversight holds a decorated tool for an approver. Instructions the output screen does not flag, and prompts that reach the model outside a tool result, are out of scope. 2026-11-10 not measured
    MCP07 Insufficient Authentication & Authorization Partial Every listed control is a helper or preset the host calls at an OAuth or MCP protocol step (authorization, discovery, request routing, step-up, Tasks); the @Airlock wrapper calls none of them. Transport-level authentication stays with the MCP server. 2026-11-10 not measured
    MCP08 Lack of Audit and Telemetry Partial The @Airlock wrapper writes a JSON Lines record for every call it handles, refused calls included (on by default), and a hash-chained decision record when the config sets a DecisionLog. OpenTelemetry export and spans and metrics run only where the host wires them; the wrapper emits neither. Context changes and model interactions outside a tool call are not recorded. Was Full until 2026-11-10. 2026-11-10 not measured
    MCP09 Shadow MCP Servers Partial Attested admission and the LAN guard check a server the host routes through them, before its tools are used. Finding an MCP server deployed outside governance, which never reaches these checks, is out of scope. 2026-11-10 not measured
    MCP10 Context Injection & Over-Sharing Partial The sanitizer masks the PII and secrets its detectors find in each result (on by default), and ToolOutputTrustGuard envelopes flagged output when the config sets one. The workspace-scoped WorkspacePIIConfig applies only through sanitize_with_workspace_config(), which the host calls. Context the host shares or keeps across tasks, users or agents, and sensitive data no detector matches, are out of scope. Was Full until 2026-11-10. 2026-11-10 not measured

    Controls¶

    Each control is named as the README names it. Runs: an @Airlock step (the # Step N comments in core.py), @Airlock execute, post-execution or wrapper (the decision record, written around the steps), a decorator of its own, or host-called: a helper the host calls itself, which the @Airlock wrapper never calls.
