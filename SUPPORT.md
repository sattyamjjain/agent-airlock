# Support

## Questions and usage help

- **[GitHub Discussions](https://github.com/sattyamjjain/agent-airlock/discussions)** — how do I do X, does this work with Y, is this the right tool for Z.
- **[Documentation](https://sattyamjjain.github.io/agent-airlock/)** — guides, API reference, CLI, per-framework integration pages.
- **[`examples/`](examples/)** — runnable scripts, one per framework. Most of them run without an API key.

## Bugs and feature requests

Open an [issue](https://github.com/sattyamjjain/agent-airlock/issues). The templates ask for
a reproduction because, for a validation library, the argument shape that got through is
usually the whole bug report.

There is also a **CVE rule request** template if you want a guard against a specific
disclosed advisory. A primary-source URL is required — see
[`tests/cves/README.md`](tests/cves/README.md) for how those are scoped, including the
reasons a CVE is sometimes declined.

## Security vulnerabilities

**Do not open a public issue.** Follow [`SECURITY.md`](SECURITY.md), which uses private
GitHub Security Advisories.

## What to expect

One maintainer ([`MAINTAINERS.md`](MAINTAINERS.md)), working on this alongside other things.
Security reports are triaged first. Everything else is best-effort, and an unanswered issue
means it has not been read yet rather than that it has been rejected.
